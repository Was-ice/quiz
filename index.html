关于本应用

AI 智能答题工具 · 使用说明

1. 浏览器打开 platform.deepseek.com
2. 注册并登录账号
3. 左侧菜单点「API keys」→「创建 API key」
4. 复制以 sk- 开头的字符串
5. 回到设置页，粘贴到「DEEPSEEK API KEY」输入框

⚠ 注意：API Key 只保存在你手机浏览器的本地存储里，不会上传到任何服务器。账户余额不足时请到 DeepSeek 官网充值。
iPhone：Safari 打开本页 → 底部分享按钮 →「添加到主屏幕」
Android：Chrome 打开本页 → 右上角菜单 →「添加到主屏幕」
添加到主屏幕后使用更接近原生 App。数据保存在浏览器本地，清理浏览器数据仍会丢失，请定期导出备份。
📝 答题页：选择学科和难度，AI 实时出题。支持选择题、填空题、简答题和文章写作；可看微提示、直接看答案、收藏题目。
📚 学习页：知识点列表 + 思维导图。点思维导图节点上的「讲解」可生成详细讲解，并可就地做「举一反三」练习。
🔁 错题本：答错的题自动收录，支持重做、查看答案、移除；重做答对后自动移出。
⭐ 收藏夹：把值得复习的题收进来，随时集中练习。
📊 数据统计：总正确率、连续答题、最近 7 天趋势与学科掌握度。
📋 记录页：按「全部 / 答错 / 简答 / 文章」筛选，按天分组查看。
⚙ 设置：主题色、18 档难度、附加提示词、背景、音效震动、连接测试与数据备份。
性能：移除阻塞式调试脚本；卡片不再逐层模糊；背景改为独立图层；本地存储去重与合并写入；已出题库改用集合判重，长会话不卡顿。
稳定：接口超时与自动重试、错误提示更准确、JSON 解析容错、修复特殊字符导致的排版错乱、修复背景图写入配置导致的存储膨胀。
新增：错题本、收藏夹、数据统计、看答案、键盘快捷键、音效/震动/自动下一题开关、连接测试、记录筛选与按天分组。
内容：新增人工智能、环境科学、金融常识等学科；新增出题提示词模板；优化出题与批改提示词。
所有配置、答题记录、错题本、收藏夹、已出题库保存在浏览器 localStorage，背景图保存在 IndexedDB。清除浏览器数据会丢失。建议定期用设置里的「导出配置」备份到备忘录。API Key 仅存本机，不会上传到除 DeepSeek 之外的任何服务器。
